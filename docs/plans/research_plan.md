# 当前研究计划

更新：2026-10-23。本文件只描述当前目标、任务和进入条件；案例证据、已有结果与文献限制见[研究报告](../reports/research_report.md)，文件说明见 [DXM](../../DXM/README.md) 与 [MCT](../../MCT/README.md)。

## 1. 研究问题与范围

检验 TAPS 构象采样＋QM/MM 化学计算＋动力学网络，能否在独立体外参照下得到定义一致的代谢速率/表观参数，并在冻结共享背景后改善 PBPK 暴露预测。首例为 DXM→DXO／human CYP2D6；MCT→dehydromonocrotaline／rat CYP3A1 为附加探索例，进入正式比较前先补齐单酶/产物证据并修正母体背景模型。

当前不扩展到全部 PA、DDI 或跨物种迁移。OSP 原拟合模型用作参考骨架；结论限定为继承背景条件下的增量预测能力。`OSP_reproduction` 不属于当前工作范围。

## 4. M1 当前要完成的四件事

1. **回溯 DXM 体外参数。** 从 Lutz 2012 等原始 assay 核对底物/产物、酶体系、突变/构建体、温度、pH、辅因子、酶量、初速与结合校正。OSP 的优化 kcat 不替代这个任务。形成包含来源、单位、终点和可比性的参数矩阵。
2. **冻结评价数据用途。** 逐研究标记原模型开发/评价用途、本研究开发/评价用途、剂量盐型、制剂、途径、表型/基因型、分析物与测量定义。Capon 母药映射不能扩成已测 DXO；不随机拆同曲线时间点作训练/测试。
3. **确定分子计算目标。** 决定是否将 2F9Q 工程残基回变、补片段，以及目标 CYP2D6 序列与临床活动评分的映射。先限定一个反应和可验证量，明确 kchem、koff 与有效 kcat 的不同含义。
4. **预登记比较与停止规则。** 固定 G2-control 的算力预算、重复和共同分析；登记速率/参数及 PK 指标、不确定性水平、可接受的 assay 可比性。不得以期望 PK 结果反选量化方法或势垒修正。

| Q4 路径 | 反应物/中间体/过渡态/产物连通性、原子与质子收支、位点选择性、构象/方法依赖；区分 ΔE‡ 与 ΔG‡ |
| Q5 速率 | 自由能窗口重叠、迟滞、独立重复及长度收敛；温度、参考态、标准态、速率理论和必要修正；s⁻¹→min⁻¹ 乘 60 |

静态路径只支持机制/排序；收敛自由能与适当理论才支持条件化学速率；完整有效网络才允许推导可比较的 kcat/Km。若从已形成 Compound I 出发，必须说明尚未覆盖上游活化。每次计算保存输入哈希、参数、状态、方法、版本、资源、种子、原始结果、失败与收敛记录。

## 6. 评价与解释

主曲线指标为 `GMFE = 10^mean(|log10(P/O)|)`，只在实际观测时刻、正值且可定量数据计算。按研究/剂量/途径汇总；多研究可按研究聚类 bootstrap。AUC0–t、Cmax 同时报 P/O 和 `max(P/O,O/P)`；Tmax 报小时差。终末相不可靠时不比较半衰期。

0.5–2 倍范围仅作辅助描述；非劣效界值须结合 assay 误差预先定义。传播 Km/kcat 联合不确定性，保留相关性，分开报告酶丰度、结合和背景结构的不确定性。只有加入个体变异和观测误差后才称为相应观测的预测区间；均值曲线不能说明个体覆盖率。

| 结果 | 应优先排查 |
|---|---|
| G1、G2 都差 | 共享模型结构、结合/丰度/IVIVE、数据口径 |
| G1 合理、G2 差 | 网络遗漏、真实速率恢复、化学态/机制、归一化 |
| G2 曲线好、参数不合理 | 参数补偿、数据泄漏、低浓度只识别 Vmax/Km |
| G0 与 G1/G2 几乎无差 | 参数是否实际生效、剂量/途径区分度 |
| G2 与 control 无差 | 报告联合方法效果；不声称 TAPS 独有增益 |

## 7. MCT 的并行任务与停止条件

先核对 MCT→脱氢产物的大鼠 CYP3A1/3A2 等贡献及反应特异数据，建立经原文结构与原子映射核验的目标产物；MNO、DHP 或加合物不能直接替代完整脱氢产物。现有母体 PK 无法识别全部代谢支路。

利用已下载作者代码比较七室 PBK 与当前 PK-Sim 的吸收、分配、肝细胞交换和缩放；先由 IV 约束背景，再评价 PO。若使用 Lin IV/PO 调参，明确记为校准或条件性预测，另留独立研究检验。Suparmi 高剂量放射性当量不作为 Lin 低剂量母体的同义验证数据。

结构不可信时停在体系准备；自由能不收敛时停在机制；完整循环缺失时停在 kchem；独立 assay 或酶归属不足时保留探索结论。现有公开数据不足时，交付缺口与可检验假设，不补造参数或宣称完成定量验证。
